# The Techy Baba — Phase 1 Frontend

A responsive React + Vite starter for The Techy Baba, using a hybrid dark/light visual system.

## Run locally
1. Install Node.js (LTS).
2. In this folder run `npm install`
3. Run `npm run dev`
4. Open the local URL printed by Vite.

## Current scope
- Responsive homepage, category discovery, product grid, search and category filtering
- Demo product cards, save-to-wishlist interaction, user/developer sign-in modal placeholders
- Affiliate CTA placeholders
- Hybrid design system

## Important
This is Phase 1 UI only. Authentication, real product persistence, admin authorization, affiliate URLs, comparison logic and analytics are not connected yet. Demo prices/products are placeholders. Before production, replace them with verified data and implement server-side authorization.
